Q学習とSARSAの違い

どちらも行動価値（Q値）を少しずつ更新していく強化学習の方法です。違いは、更新のときに使う「次の行動の価値」が、最も良い行動のものか、実際に選んだ行動のものか、です。

表で比べる

観点Q学習SARSA
更新に使う次の価値次の状態で最も良い行動の価値（最大の Q値）次の状態で実際に選んだ行動の価値
方策との関係方策オフ型（実際の行動の選び方と別に学ぶ）方策オン型（実際の行動の選び方に沿って学ぶ）
名前の由来行動価値 Q を学ぶState・Action・Reward・State・Action の頭文字

見分けるポイント

  • 「最大の Q値で更新」なら Q学習
  • 「実際に選んだ行動で更新」なら SARSA
  • どちらも、探索と活用のバランスに ε-greedy方策などを使える
  • Q学習の行動価値をディープラーニングで近似したものが DQN

試験での出され方

「次の状態で実際に選択した行動の価値を使って更新する手法はどれか」のように、更新のしかたの説明から名前を選ばせる問題が出ます。SARSA の名前が、更新に使う5つの要素の頭文字だと覚えておくと区別しやすくなります。

それぞれの用語

  • Q学習

    行動価値（Q値）を、次の状態で最も良い行動の価値を使って更新していく強化学習の方法。

  • SARSA

    行動価値を、次の状態で実際に選んだ行動の価値を使って更新する強化学習の方法。
