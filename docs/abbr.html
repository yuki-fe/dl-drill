AI・ディープラーニングの略語クイズと早見表（37語）

G検定の用語には、GPU・LSTM・GAN・PCA のような略語がたくさんあります。略語は、元の英語（正式名）と一緒に覚えると、仕組みも思い出しやすくなります。

略語の早見表

人工知能とその動向機械学習ディープラーニングの技術ディープラーニングの応用社会実装と数理・統計法律・倫理

機械学習

略語正式名意味
サポートベクターマシン（SVM）Support Vector Machineクラスの境界とデータの間の距離（マージン）を最大にする境界を見つける分類の方法。
主成分分析（PCA）Principal Component Analysisデータのばらつきが大きい方向（主成分）を見つけて、少ない次元にまとめる次元削減の方法。
多次元尺度構成法（MDS）Multi-Dimensional Scalingデータどうしの距離（似ていなさ）をなるべく保ったまま、低い次元に配置する方法。
平均二乗誤差（MSE）Mean Squared Error予測と正解の差を2乗して平均したもの。その平方根が二乗平均平方根誤差（RMSE）、差の絶対値の平均が平均絶対値誤差（MAE）。
特異値分解（SVD）Singular Value Decomposition行列を3つの行列の積に分ける計算。次元削減や推薦などに使う。
自己回帰モデル（ARモデル）Autoregressive Model過去の自分の値から、次の値を予測する時系列のモデル。複数の時系列を同時に扱うものはベクトル自己回帰モデル（VARモデル）。

ディープラーニングの技術

略語正式名意味
BPTTBackpropagation Through TimeRNN を時間の方向に展開して、誤差逆伝播法で学習する方法。
GPUGraphics Processing Unit画像処理用の演算装置。同じ計算を大量に並列で行うのが得意で、ディープラーニングの学習に向く。
GRUGated Recurrent UnitLSTM を簡単にした RNN。リセットゲートと更新ゲートの2つで情報を調整する。
LSTMLong Short-Term Memoryゲート機構と記憶セル（CEC）で、長い時系列でも大事な情報を覚えておけるようにした RNN。
TPUTensor Processing UnitGoogle が作った、ディープラーニングの計算に特化した演算装置。
グローバルアベレージプーリング（GAP）Global Average Pooling特徴マップ全体の平均を1つの値にするプーリング。全結合層の代わりに使い、パラメータを減らせる。
リカレントニューラルネットワーク（RNN）Recurrent Neural Network前の時点の情報を次に引き継ぐ回帰結合層を持つネットワーク。時系列データや文章を扱う。
双方向RNNBidirectional RNN過去から未来と、未来から過去の両方向に情報を流す RNN。文の前後の両方を使える。
変分オートエンコーダ（VAE）Variational Autoencoder潜在変数を確率分布として学ぶオートエンコーダ。新しいデータを生成できる。VQ-VAE・info VAE・β-VAE などの改良版がある。
確率的勾配降下法（SGD）Stochastic Gradient Descentデータを1つずつ、またはランダムに選んだ一部で勾配を計算して、重みを更新する方法。

ディープラーニングの応用

略語正式名意味
A3CAsynchronous Advantage Actor-Critic複数のエージェントが並列に、非同期で学習する Actor-Critic の方法。
BoW（Bag-of-Words）Bag-of-Words文章を、単語の順番を無視して、どの単語が何回出たかで表す方法。
CTCConnectionist Temporal Classification音声と文字のように、入力と出力の長さが違う系列を、位置を合わせずに学習できる方法。音声認識で使う。
DCGANDeep Convolutional GAN生成器と識別器に畳み込みニューラルネットワークを使った GAN。
DQNDeep Q-NetworkQ学習の行動価値を、ディープラーニングで近似する方法。経験を貯めて使い直す工夫などで、ゲームを人間並みにこなした。
FCNFully Convolutional Network全結合層を使わず、すべて畳み込み層で作った、画素ごとに分類するセグメンテーションのモデル。
FPNFeature Pyramid Network大きさの違う特徴マップを組み合わせて、大小さまざまな物を検出しやすくする仕組み。
GAN（敵対的生成ネットワーク）Generative Adversarial Networkデータを作る生成器と、本物か偽物かを見分ける識別器を競わせて学ぶ生成モデル。
NAS（ニューラルアーキテクチャサーチ）Neural Architecture Searchネットワークの構造そのものを、自動で探して決める方法。MnasNet はこれで作ったモバイル向けのモデル。
NeRFNeural Radiance Fieldsいくつかの方向から撮った写真から、3次元の場面を学んで、別の方向から見た画像を作る方法。
PPOProximal Policy Optimization方策を一度に大きく変えすぎないように制限しながら学習する、安定した強化学習の方法。
SSDSingle Shot MultiBox Detector大きさの違う複数の特徴マップを使って、1回の処理で物体を検出するモデル。
マルチエージェント強化学習（MARL）Multi-Agent Reinforcement Learning複数のエージェントが、同じ環境で協力したり競争したりしながら学ぶ強化学習。
メル周波数ケプストラム係数（MFCC）Mel-Frequency Cepstral Coefficientsメル尺度を使って、声の特徴（スペクトル包絡）を表す数の組。音声認識でよく使われた。
大規模言語モデル（LLM）Large Language Model大量の文章で事前学習した、大規模な言語モデル。文章の生成・要約・翻訳・質問応答などができる。PaLM などがある。
説明可能AI（XAI）Explainable AIAI が、なぜその判断をしたのかを、人が理解できるように示す技術や考え方。
高速フーリエ変換（FFT）Fast Fourier Transform音などの波を、どの周波数の成分がどれだけ含まれるか（周波数スペクトル）に、速く分解する計算。

社会実装と数理・統計

略語正式名意味
BPRBusiness Process Re-engineering業務の流れを根本から見直して作り直すこと。AI の導入にあわせて行うことがある。
CRISP-DMCross-Industry Standard Process for Data Miningデータ分析のプロジェクトの進め方の標準。ビジネスの理解・データの理解・データの準備・モデリング・評価・展開の流れ。機械学習向けに発展させたものが CRISP-ML。
PoCProof of Concept概念実証。本格的に作る前に、AI で本当に効果が出るかを小さく試して確かめること。
