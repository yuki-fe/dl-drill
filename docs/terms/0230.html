Docker と Jupyter Notebook

AI の開発でよく使う道具。Docker はアプリと動く環境をまとめて動かす仕組み。Jupyter Notebook はプログラムと結果を並べて試せる環境。

同じ分野の用語

  • アジャイルとウォーターフォール

    開発の進め方。アジャイルは小さく作って直すのをくり返す。ウォーターフォールは決めた工程を順番に進める。AI の開発はアジャイルが向くことが多い。

  • Web API

    インターネットを通して、ほかのプログラムの機能を呼び出す窓口。学習済みモデルを公開して使ってもらうときに使う。

  • BPR

    業務の流れを根本から見直して作り直すこと。AI の導入にあわせて行うことがある。

  • アノテーション

    学習データに、正解のラベルや情報を付ける作業。

  • MLOps

    機械学習のモデルを、開発から運用・監視・改善まで、継続して回していくための考え方と仕組み。

  • データリーケージ

    本当は予測のときに使えない情報（テストや未来の情報など）が学習に混ざり、評価が実際より良く見えてしまうこと。
