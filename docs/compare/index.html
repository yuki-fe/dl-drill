似た用語の違いG検定でまぎらわしい用語 15組

試験では、似た用語の違いがよく問われます。2つ（3つ）の用語を表で並べて、どこが違うかを確かめましょう。

  • シグモイド関数とtanh関数とReLU関数の違い

    どれもニューラルネットワークの活性化関数です。出力の範囲と、層を深くしたときの勾配の消えにくさが違います。隠れ層では、勾配が消えにくい ReLU 関数がよく使われます。

  • L1正則化とL2正則化の違い

    どちらも、重みが大きくなりすぎないように罰を加えて、過学習を防ぐ方法です。L1正則化は不要な重みを0にしやすく、L2正則化は重みを全体に小さくします。

  • 適合率と再現率とF値の違い

    どれも分類のモデルの良さを測る指標です。適合率は「陽性と言ったものがどれだけ正しいか」、再現率は「本当の陽性をどれだけ見つけられたか」、F値はその2つのバランスです。

  • Q学習とSARSAの違い

    どちらも行動価値（Q値）を少しずつ更新していく強化学習の方法です。違いは、更新のときに使う「次の行動の価値」が、最も良い行動のものか、実際に選んだ行動のものか、です。

  • バギングとブースティングとランダムフォレストの違い

    どれも複数のモデルを組み合わせるアンサンブル学習です。バギングはモデルを並列に別々に作り、ブースティングは前の間違いを直しながら順番に作ります。ランダムフォレストはバギングに決定木を使ったものです。

  • 主成分分析（PCA）とt-SNEの違い

    どちらも、たくさんの特徴（次元）を持つデータを、少ない次元にまとめる次元削減の方法です。主成分分析はばらつきの大きい方向を残し、t-SNE は近いデータどうしの近さを残して、2〜3次元の図にするのが得意です。

  • RNNとLSTMとGRUの違い

    どれも、前の時点の情報を次に引き継いで、文章や時系列のデータを扱うネットワークです。ふつうの RNN は長い系列を覚えるのが苦手で、それをゲートで改良したのが LSTM、LSTM を簡単にしたのが GRU です。

  • セマンティックセグメンテーションとインスタンスセグメンテーションの違い

    どちらも、画像を画素（ピクセル）ごとに分けるタスクです。セマンティックは種類ごとに塗り分けるだけで、インスタンスは同じ種類の物でも1つずつ区別します。

  • GANとVAEと拡散モデルの違い

    どれも新しい画像などのデータを作る生成モデルです。GAN は2つのネットワークを競わせ、VAE はデータを確率分布として縮めて戻し、拡散モデルはノイズを少しずつ取り除いてデータを作ります。

  • ワンホットベクトルと分散表現の違い

    どちらも単語をベクトル（数の並び）で表す方法です。ワンホットベクトルは単語ごとに1か所だけ1を立てるので意味の近さを表せず、分散表現は意味の近い単語ほど近いベクトルになります。

  • 協調フィルタリングとコンテンツベースフィルタリングの違い

    どちらも、利用者におすすめの商品などを決めるレコメンドの方法です。協調フィルタリングは「似た好みの人」の行動を使い、コンテンツベースフィルタリングは「商品そのものの特徴」を使います。

  • AdaGradとRMSpropとAdamの違い

    どれも、重みごとに学習率を自動で調整する最適化の方法です。AdaGrad の「学習率が小さくなりすぎる」弱点を RMSprop が改良し、RMSprop とモーメンタムの考えを合わせたのが Adam です。

  • バッチ正規化とレイヤー正規化の違い

    どちらも、層の値を平均0・分散1に整えて、学習を安定させる方法です。バッチ正規化はミニバッチの中の複数のデータで整え、レイヤー正規化は1つのデータの中で整えます。

  • CNN（畳み込み）とRNNの違い

    CNN は畳み込み層で画像の中の形の特徴を取り出すネットワーク、RNN は前の時点の情報を引き継いで、文章や時系列のような順番のあるデータを扱うネットワークです。

  • 蒸留とプルーニングと量子化の違い

    どれも、学習したモデルを軽く・速くして、スマホなどでも動かせるようにする方法です。蒸留は小さなモデルに大きなモデルをまねさせ、プルーニングは要らない部分を削り、量子化は数を少ないビットで表します。
